# Bank Soal Matematika — Kelas 1–2 (Gamifikasi)

Bank soal untuk SoalGen, format yang sama dengan `contoh/ujian-contoh.md`.
Satu file ini dipakai dua cara: dicetak jadi paket soal lewat
`bin/soalgen build`, dan dimainkan sebagai game lewat aturan di
`gamifikasi-kelas-bawah.md`.

Cara pakai (di laptop, dari folder soalgen):

    bin/soalgen build contoh/bank-soal-matematika-kelas-1-2.md --seed=7 --paket=A --out=hasil

Catatan untuk guru/orang tua: bacakan soal dengan suara saat anak main,
soal sengaja pendek dan jawabannya satu angka.
